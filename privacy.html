Privacy

Privacy across the Quire family

Each Quire extension has its own privacy policy, because each one does a different job and asks Chrome for different access. This page summarises what they share and links to each policy. The individual policies are the authoritative ones.

What every Quire reader has in common

  • No accounts. There is nothing to sign up for.
  • No analytics, advertising or tracking.
  • No uploads. Documents you open are processed in your browser and are not sent to the developer.
  • Local storage. Libraries, bookmarks, reading positions, recent documents, recovery copies and settings are kept in your Chrome profile on your computer. Removing the extension or clearing browser data can delete them.
  • Documents from the web. When you open a document from a link, the extension requests that file from the site that hosts it. That site sees the request, as it would for a normal download.

Each product's policy

  • Quire – EPUB Reader Read the EPUB Reader privacy policy
    Asks for access to all websites so .epub links open in the reader. Permissions explained.
  • Quire PDF – Reader & Editor Read the Quire PDF privacy policy
    Asks for access to a website only when you open a PDF from it.
  • Quire Markdown – Viewer Read the Quire Markdown privacy policy
    Asks for access to a website only when you open a Markdown link from it. In Chrome Web Store review.

This website

This page and the Quire homepage are static files. They set no cookies, run no analytics and load nothing from other servers: no fonts, scripts or trackers. The site is hosted on GitHub Pages, and GitHub may keep standard server logs of requests, such as IP addresses, under GitHub's privacy statement.
