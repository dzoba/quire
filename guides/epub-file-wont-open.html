EPUB file won’t open? Common causes and how to fix them

Short answer: most EPUB files that “won’t open” fall into one of five cases. There is no EPUB reader on the computer, the file is really an .acsm ticket, the book has DRM, the download was cut short, or the file itself is faulty.

The checks below take a minute each and tell you which one you have.

Updated 15 October 2026. Quire’s error messages checked in Chrome for Testing 153 on a Mac.

Work through these checks

  1. Make sure something can read EPUB

    Windows has no EPUB reader built in, and Chrome downloads .epub files instead of opening them. A Mac has Apple Books. If double-clicking does nothing useful, install a reader first: see the guides for Windows, Mac, Chrome and Chromebook.

  2. Check the real file type

    If the file name ends in .acsm, it isn’t the book. It is a small ticket that Adobe Digital Editions uses to download a DRM-protected book; see how to open an .acsm file. Make sure your computer shows file extensions, so that “book.epub.html” or “book.epub.zip” doesn’t pass for an EPUB.

  3. Look at the file size

    A whole book is usually hundreds of kilobytes or more. A file of a few kilobytes is more likely a ticket, a saved error page or a download that stopped early.

  4. Download it again

    An EPUB is a ZIP archive with the book’s pages inside. If the download was interrupted, the archive is incomplete and readers refuse it. Download the book again from the original page, ideally on a steady connection.

  5. Try a second reader

    Readers differ in how strictly they treat small mistakes in a book’s files. If one reader fails and another opens the same file, the file is fine. calibre and Thorium are both free, so either is easy to try as a second reader.

  6. Consider DRM

    calibre’s FAQ says: “Most purchased EPUB books have DRM.” A protected book only opens in the app it was sold for, or in Adobe Digital Editions. See DRM-free vs DRM-protected EPUB.

What Quire EPUB Reader’s messages mean

If you use Quire, our Chrome extension, it tells you which problem it found instead of showing a blank page. A file that fails is not added to your library.

  • “This is not an EPUB file”. The file isn’t a ZIP archive at all. It may be a web page, a different format, or an .acsm ticket. We dropped an .acsm file onto the library to check, and this is the message it gave.
  • “This EPUB file is damaged”. The archive is incomplete, usually because the download was cut short. Download it again. A copy of a book cut off at 40% of its size gave this message in our test.
  • “This EPUB could not be opened”. The archive is intact but required parts of the book are missing. Try another reader, or another copy of the book.
  • “This file is empty”. The download finished with no data. The link may have expired, or needed you to sign in.
  • “The server answered 403” (or 401). The site refused the download. Sign in on that site, then click the link again. 404 means the book is no longer at that address.
  • The book opens, but the text is scrambled characters. This is most likely DRM. We built a test file that imitates Adobe’s encryption: Quire opened it and showed the title, then strings of random symbols instead of the text. Quire can’t open DRM-protected books, so read it in the store’s app and remove it from your library with the trash button on its cover.

If the book is free and none of this helps

Look for another copy. Public-domain classics are available from more than one source, and Project Gutenberg and Standard Ebooks both offer DRM-free EPUB files that open in any reader.
