How to open an .acsm file

Short answer: an .acsm file is not the book. It is a small ticket from the shop or library that tells Adobe Digital Editions (ADE) which protected book to download and for whom. Install ADE, which is free, authorize it, then open the .acsm file in it.

Ordinary EPUB readers can’t open .acsm files. Apple’s Books guide, for example, says ACSM files “can only be opened in the associated third-party app”.

Updated 15 October 2026. ByteBooks details are from OverDrive’s help; ADE details from Adobe’s FAQ.

Open an .acsm file in Adobe Digital Editions

  1. Install Adobe Digital Editions

    Download it from Adobe’s download page. Adobe describes it as a free eReader for computers, and there are mobile versions too.

  2. Authorize ADE with a ByteBooks ID

    Use the authorize option in ADE’s Help menu. Since 23 June 2026, ByteBooks IDs have replaced Adobe IDs for this. Computers already authorized with an Adobe ID keep working, but authorizing a new one needs a ByteBooks ID. If you used an Adobe ID before, create the ByteBooks ID with the same email address so you keep access to books you downloaded earlier.

  3. Open the .acsm file

    Double-click it, or right-click it and open it with Adobe Digital Editions. ADE contacts the shop or library and downloads the real book, which may be an EPUB or a PDF.

  4. Read it, or move it to an e-reader

    Read in ADE, or connect your e-reader and drag the book onto the device’s name in ADE, as Google’s Play Books help describes.

What you end up with

The book ADE downloads is still protected with Adobe DRM. It opens in ADE and in apps and e-readers authorized with the same account, but not in readers without Adobe DRM support. That includes Apple Books, calibre, Google Play Books uploads and Quire EPUB Reader. Keep the book in ADE, or in the app your shop or library recommends.

Limits

  • Six devices. Adobe’s FAQ says you can activate up to six computers and devices. If you hit the limit, contact customer support to reset it.
  • One account per book. Google’s help says each purchased ebook “is tied to a single Adobe ID”, so open it with the same account every time.
  • Library loans expire. The Internet Archive, for example, returns a downloaded loan automatically “within 14 days”.
  • Not every book can be downloaded. Google notes that some publishers don’t allow exports and rented books can’t be exported at all.

Books from particular places

  • Google Play Books: on play.google.com, open your profile, go to Library & devices › Books, click More next to the book, then Export. You get an EPUB, a PDF or an .acsm file depending on the book. You can also read Play Books purchases in the Play Books website or apps without ADE.
  • Library and Internet Archive loans: some lenders now use Readium LCP instead of Adobe DRM. Thorium Reader opens LCP-protected books. The Internet Archive says its lending library has “switched over to LCP” for offline reading.

If you want a book you can open anywhere

Look for a DRM-free edition. Some publishers sell them, and public-domain books are free from Project Gutenberg and Standard Ebooks. To understand the different kinds of protection, see DRM-free vs DRM-protected EPUB.
