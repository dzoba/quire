Why can’t I edit the text in a PDF?

Short answer: usually one of three things. Your PDF tool only adds annotations on top of the page, which is true of Chrome, Edge, Preview, the free Acrobat Reader and our own Quire PDF. Or the PDF is a scan, a picture of a page with no text in it. Or the PDF simply wasn’t designed to be edited: it stores where each piece of text sits, not paragraphs that reflow.

To change the words, convert the PDF in Word or LibreOffice, use a paid editor such as Adobe Acrobat, or ask for the original document.

Updated 15 October 2026. Word steps follow Microsoft’s Word help.

Why PDF text is hard to edit

Microsoft puts it plainly: PDF is a fixed format, which stores the location of text, pictures and graphics on a page, but not necessarily how they relate to each other. There may be no “paragraph” to edit, just lines or fragments of text placed at exact positions. Adobe notes that even in Acrobat, each text box is independent, so added words don’t push the next block down or flow onto the next page.

Most free tools don’t attempt it at all. Apple’s Preview guide says you can’t edit the text of a PDF in Preview and suggests the markup tools instead. Adobe says text and image editing isn’t in the free Acrobat Reader. Chrome’s and Edge’s viewers add text, highlights and drawings on top of the page.

Is it a scan?

Try to select a word. If you can’t, or the whole page selects as one block, the PDF is probably a scanned image with no text. Nothing can edit text that isn’t there; it first needs OCR (text recognition). Google says Chrome’s viewer can run OCR on scanned PDFs so you can select and search the text, and Adobe says paid Acrobat runs OCR automatically when you edit a scan.

Change the words with Word

  1. Open the PDF from Word

    In Word, choose File › Open and pick the PDF. You may need to select Browse to find it.

  2. Let Word convert a copy

    Word says it will make a copy of the PDF and convert it into a format it can display. Select OK. The original PDF stays unchanged.

  3. Edit the text

    Change the words as in any Word document. Check headers, footnotes and tables, which Microsoft says may not convert perfectly.

  4. Save it as a PDF again

    Choose Export › Create PDF/XPS Document › Create PDF/XPS, pick where to save it, and select Publish.

Microsoft says this works best for mostly-text files such as business, legal or scientific documents, and the result may not look exactly like the PDF. Pages that are mostly charts or graphics may come through as a single image.

Other ways to change PDF text

  • LibreOffice Draw is free and open source, and its documentation says it can edit the contents of a PDF. Compare the result with the original, because complex layouts don’t always come through intact.
  • Adobe Acrobat Standard or Pro (paid) edits text in place and handles scans with OCR.
  • The original file. If someone made the PDF from a Word or Google document, asking them for that file is often the quickest fix.

If you only need to add or cover a few words

For filling a gap, adding a date or correcting a figure in a copy for yourself, an annotation tool is enough: add your text on top of the page. See how to add text to a PDF. A white box with new text on it can hide an old word on screen, but the original text is still in the file and can be selected or searched, so never use it to hide private information.

Quire PDF, our Chrome extension, is one of these annotation tools. Its Text tool adds text and its Draw tool can cover things up, but it doesn’t edit or replace the original text and it has no OCR or secure redaction. If you need to rewrite a PDF, use one of the options above.
