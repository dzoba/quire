How to view Markdown (.md) files in Chrome

Short answer: Chrome shows a Markdown file as plain text. Drag a .md file into Chrome, or open a raw .md link, and you get the source with its # and * characters, not formatted headings and lists.

To see it formatted without installing anything, use GitHub (for files in a repository) or the preview built into VS Code. A Markdown viewer extension shows it formatted right in Chrome.

Updated 12 October 2026. Plain-text behaviour checked in Chrome 155 on a Mac.

Options that need no extension

  1. Read the plain text in Chrome

    Drag the .md file into a Chrome window, or press Ctrl+O (⌘+O on a Mac) and choose it. Markdown is designed to be readable as plain text, so this is fine for a short README.

  2. View it on GitHub

    If the file is in a GitHub repository, open it on github.com. GitHub shows Markdown files formatted, and you can switch to the source with the Code button above the file.

  3. Preview it in VS Code

    VS Code supports Markdown out of the box. Open the file and press Ctrl+Shift+V (⇧⌘V on a Mac) for a preview, or Ctrl+K then V (⌘K V) to see it side by side with the source. Most code editors have something similar.

Other good options

  • Your code editor’s preview, as above. Good when you are editing the file anyway.
  • GitHub, for anything already in a repository.
  • Other Markdown extensions are available on the Chrome Web Store today. Before installing one, check what site access it asks for.

Questions

Can Chrome display Markdown files?

Chrome opens .md files as plain text. You see the Markdown source, with # for headings and * for lists, rather than formatted text. That is readable for short notes but not for long documents with tables or code.

How can I see formatted Markdown without installing anything?

If the file is in a GitHub repository, open it on github.com, which shows it formatted. If you have VS Code, open the file and press Ctrl+Shift+V (Shift+Command+V on a Mac) for its built-in preview.
