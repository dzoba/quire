Keep up with your files

Files selected with Open file can be refreshed. Turn on Follow file to read changes every two seconds while this tab is visible. Quire never writes to the original file. Following ends when this tab closes or you open another document. Dropped files are snapshots; use Open file to follow them.

Private by default

The ten most recent documents are stored in this browser, on this device. The × beside a recent document removes that local copy. Clearing this site's data in your browser erases them too. Downloaded files and original files are separate.

Document scripts, embedded frames, styles and images are blocked. Diagrams and math remain source text. No account, analytics, advertising, cloud processing or AI calls. This page never fetches documents from the web.
