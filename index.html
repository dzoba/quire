The family

One job each, done carefully.

Quire is three separate extensions rather than one that does everything. Install only what you read, and each asks Chrome only for the access its own job needs.

Quire – EPUB Reader

On the Chrome Web Store

Click a link to an .epub file and it opens right in Chrome, in a clean reader.

  • Search every chapter at once, with matches highlighted
  • Bookmarks and your reading position stay put after you close the tab
  • Page or scroll mode; light, sepia and dark themes
  • A library of your books with covers and progress
  • Read aloud, with the current paragraph highlighted

Good to know: read aloud uses the voices installed on your computer. Scripts inside EPUB files are blocked. Works with EPUB 2 and EPUB 3.

To open book links on any site, it asks Chrome for access to all websites. Why it needs that.

Quire PDF – Reader & Editor

On the Chrome Web Store

Read, annotate, fill forms and organize PDFs, then save an edited copy on your computer.

  • Text search, page thumbnails and the document outline
  • Highlights, comments, text, drawings, images and a drawn or typed signature
  • Fill the standard form fields already in a PDF
  • Reorder or remove pages, combine PDFs, export selected pages
  • A local library, with recovery for unfinished work

Good to know: Quire PDF adds to a page; it does not rewrite the original text. It has no OCR, no secure redaction and no certificate-based signing, and a signature is a visual mark. XFA forms and PDF scripts are not supported.

Browser storage is not a backup, so download a copy of important work.

Quire Markdown – Viewer

In review – coming soon

A focused viewer for README files, technical notes and coding-agent plans.

  • Heading outline, find, and rendered, source or split views
  • Tables, task lists and syntax-highlighted code with a copy button
  • Refresh or follow a local file while your editor changes it

Good to know: it is a viewer, not an editor, and never overwrites your file. It opens UTF-8 text up to 2 MB. Images appear as blocked references, and diagrams and math are not rendered.

Private by design

Your documents stay on your computer.

Every Quire reader is local-first. None of them sends the documents you open to the developer or to anyone else.

No accounts

Nothing to sign up for or log in to. Install it and open a file.

No tracking

No analytics, advertising or tracking code in any of the three.

No uploads

Different jobs, different permissions

Each extension asks Chrome for different access. Here is the short version; each product's own page explains every permission in full.

EPUB Reader

Asks for access to all websites so a click on any .epub link opens in the reader, and the book can be fetched from the site that hosts it. It has no content scripts and does not read or change the pages you visit. Opening books forced to download is optional and asked separately.

EPUB permissions explained

PDF

Uses activeTab and contextMenus. When you open a PDF from a link, it asks for access to that one website at that moment. Local files need no site access.

PDF privacy and permissions

Markdown

Uses activeTab and contextMenus. Opening a raw Markdown link asks for access to that one website and fetches the file without cookies. Local files need no site access.

Questions

Good to know.

Anything else? Each product has its own issue tracker, linked at the bottom of the page.

Do I need an account?

No. None of the Quire readers has accounts or sign-in. Install one from the Chrome Web Store and open a file.

Are my documents uploaded anywhere?

No. Files are opened and processed in your browser, and anything kept for later, such as a library, recovery copy or recent document, is stored in your Chrome profile. When you open a document from a web link, the request goes to the site that hosts it, the same as downloading it.

Why are these three extensions and not one?

Each job needs different access. Opening every .epub link on the web needs broad site access, while the PDF and Markdown readers only ask for a website when you open something from it. Keeping them separate means you only grant what the reader you use actually needs.

Can Quire PDF edit the text in a PDF?

Not the original text. It adds highlights, notes, text, drawings, images and signature marks, fills existing form fields, and rearranges pages. It does not do OCR, secure redaction or certificate-based digital signing.

When can I install Quire Markdown?

It has been submitted and is waiting for Chrome Web Store review. An install button will appear here once it is approved. Until then, its website describes what it does.

What does it cost?

All three are free, with no ads. Quire EPUB Reader and Quire PDF are on the Chrome Web Store now; Quire Markdown can be installed once its review finishes.

Does browser storage replace a backup?

No. Uninstalling an extension or clearing browser data can remove what it stored. Keep your original files, and download copies of edited PDFs you care about.
