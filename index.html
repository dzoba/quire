Extensions

The three extensions

There is one extension for each file type. Install only the ones you need. Each one asks Chrome only for the access that its own file type requires.

Quire – EPUB Reader

On the Chrome Web Store

Click a link to an .epub file and the book opens in a Chrome tab.

  • Search every chapter at once, with matches highlighted
  • Bookmarks and your reading position are kept after you close the tab
  • Page or scroll mode, and light, sepia and dark themes
  • A library of your books with covers and progress
  • Read aloud, with the current paragraph highlighted

Good to know: read aloud uses the voices installed on your computer. Scripts inside EPUB files are blocked. Works with EPUB 2 and EPUB 3.

To open book links on any site, it asks Chrome for access to all websites. Why it needs that.

Quire PDF – Reader & Editor

On the Chrome Web Store

Read, annotate and sign PDFs, fill in forms and rearrange pages, then save an edited copy on your computer.

  • Text search, page thumbnails and the document outline
  • Highlights, comments, text, drawings, images and a drawn or typed signature
  • Fill the standard form fields already in a PDF
  • Reorder or remove pages, combine PDFs and export selected pages
  • A local library, with recovery for unfinished work

Good to know: Quire PDF adds things on top of a page. It does not change the original text. It has no OCR, no secure redaction and no certificate-based signing, and a signature is a visual mark. It does not support XFA forms or PDF scripts.

Browser storage is not a backup, so download a copy of anything important.

Quire Markdown – Viewer

On the Chrome Web Store

Opens .md files as formatted pages. Useful for README files, technical notes and coding-agent plans.

  • Heading outline, find, and rendered, source or split views
  • Tables, task lists and syntax-highlighted code with a copy button
  • Refresh a local file, or have the view follow it while your editor changes it
  • Print or download an HTML copy
  • Light, dark or system theme

Good to know: it only displays files. You cannot edit in it, and it never overwrites your file. It opens UTF-8 text up to 2 MB. Images appear as blocked references, and it does not render diagrams or math.

Privacy

What happens to your files

Your files stay on your computer. None of the three extensions sends the documents you open to the developer or to anyone else.

No accounts

There is nothing to sign up for or log in to. Install an extension and open a file.

No tracking

None of the three contains analytics, advertising or tracking code.

No uploads

Your browser opens and processes each document. Nothing you open is sent to the developer.

Stored locally

Libraries, bookmarks, recent files and settings are saved in your Chrome profile, not in a cloud service.

Permissions each extension asks for

Each extension asks Chrome for different access. Below is a short summary. Each product's own page explains every permission in full.

EPUB Reader

Asks for access to all websites so a click on any .epub link opens in the reader, and the book can be fetched from the site that hosts it. It has no content scripts and does not read or change the pages you visit. Opening books that a site forces you to download is optional, and the extension asks for that permission separately.

EPUB permissions explained

PDF

Uses activeTab and contextMenus. When you open a PDF from a link, it asks for access to that one website at that moment. Local files need no site access.

PDF privacy and permissions

Markdown

Uses activeTab and contextMenus. Opening a raw Markdown link asks for access to that one website and fetches the file without cookies. Local files need no site access.

Markdown privacy and permissions

Questions

Frequently asked questions

For other questions, each product has its own issue tracker, linked at the bottom of the page.

Do I need an account?

No. None of the Quire extensions has accounts or sign-in. Install one from the Chrome Web Store and open a file.

Are my documents uploaded anywhere?

No. Files are opened and processed in your browser, and anything kept for later, such as a library, recovery copy or recent document, is stored in your Chrome profile. When you open a document from a web link, the request goes to the site that hosts it, the same as downloading it.

Why are these three extensions and not one?

Each job needs different access. Opening every .epub link on the web needs broad site access, while the PDF and Markdown readers only ask for a website when you open something from it. Because they are separate, you only grant the access that the extension you use needs.

Can Quire PDF edit the text in a PDF?

Not the original text. It adds highlights, notes, text, drawings, images and signature marks, fills existing form fields, and rearranges pages. It does not do OCR, secure redaction or certificate-based digital signing.

Are all three available now?

Yes. Quire EPUB Reader, Quire PDF and Quire Markdown are all on the Chrome Web Store. Install only the ones you need.

What does it cost?

All three are free and have no ads. Quire PDF is also available as a free web tool at quireapps.com/pdf, which needs no install.

Does browser storage replace a backup?

No. Uninstalling an extension or clearing browser data can remove what it stored. Keep your original files, and download copies of edited PDFs you care about.
